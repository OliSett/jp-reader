# JP Reader (phone app)

Install on iPhone: open https://OliSett.github.io/jp-reader/ in Safari → Share → Add to Home Screen.
Link it with the JP Reader for Anki Firefox extension from Firefox: Settings → Phone → Link a phone.

Built from the extension sources. Dictionary data: JMdict (EDRDG, CC BY-SA 4.0) via jmdict-simplified;
frequency list: Jiten.moe (CC BY-SA 4.0). These data files are shared under the same licence.
